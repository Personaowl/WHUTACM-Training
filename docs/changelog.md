- 绑定页接入 AtCoder、洛谷、Nowcoder 公开统计；缺失字段显示“—”，不伪造最高分，不混用咕值和比赛 Rating。
- 新增账号隔离快照、有限后台队列、同步去重和失败退避；前端仅在同步期间有限查询，不改变详细看板和训练验收。
