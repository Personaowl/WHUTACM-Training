## 2026-10-27：页面读取的后端优化

- 洛谷 / Nowcoder 接入公开昵称，个人中心、账号绑定及首页统一优先展示昵称；UID 验证与主页链接不变。统计快照补充可空 display_name，旧数据后台补全，缺失时回退 UID，不额外阻塞页面请求。
- 修复 Nowcoder 简介最多 25 字符导致验证码无法保存的问题：改为 24 字符的 Base64URL 挑战，仍使用 128 位安全随机值；提示临时替换简介和重新发起旧长码，洛谷与已验证账号不受影响。
- 每日一题历史默认且最多查询含今天的近 30 天；旧客户端的 days=0 也按 30 天处理。不删除旧记录，不限制热力图、周训练与管理员导出的查询范围。
- 排行榜先对 ID、积分和最后打卡时间分页，再读取该页头像；补建 `(user_id, checked_at)` 索引，完全同分同时间时增加 ID 稳定排序。
- 排行榜分页和总数增加默认 3 秒的有界请求合并缓存；最多 16 页、估算字符串占用不超过 4 MiB，超大结果不缓存。资料、身份、积分变化及事务结束后失效；事务内读取不共享，认证本身不缓存。
- 本人资料接口复用本次鉴权读取的用户，减少一次包含头像的数据库查询；管理员查看他人仍按目标 ID 查询。
- 比赛分平台成功快照写入 `contest_source_snapshot`；启动时恢复一天内快照、过滤已结束场次，并异步预热。每分钟检查是否到期，同轮来源请求仍去重；失败不覆盖上次成功快照。
- 新增隔离 MySQL 查询对照、分页/索引、缓存上限/事务隔离与重启并发回归；实测数据、边界和发布注意见 [性能记录](performance.md)。
