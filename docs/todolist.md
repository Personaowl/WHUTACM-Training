# 维护检查清单

[文档索引](README.md) · [功能与权限](features.md) · [运维](operations.md)

本文件只列后续维护建议，不再重复已实现功能。用户搜索、自动化测试、账号绑定、周记录等现状见功能文档；以下未勾选项不是已实现承诺，也不表示每次文档更新都做过这些验收。

## 每次发布

- [ ] 后端 `mvn -f backend/pom.xml clean verify` 通过。
- [ ] 前端按锁文件安装，依次通过 `npm run audit:security`、`npm test` 和 `npm run build`。
- [ ] 数据库与旧运行产物已备份，恢复路径明确；初始化器变化先在备份演练库验证。
- [ ] 目标环境登录、资料编辑、头像、绑定、Easy/Hard 校验及积分差额正常。
- [ ] 题单、推题、每日题管理、现役看板、ABC、周记录、说明审核和 Excel 导出正常。
- [ ] 普通用户不能访问管理接口或他人私人说明；超管重置密码和最后一位超管保护正常。
- [ ] 生产启用 prod、数据库/后端只监听回环，站点入口和 Nginx 配置与当前阶段（HTTP/IP 或 HTTPS）一致。
- [ ] 发布脚本的远程仓库、分支、备份凭据、健康等待和回退行为经过实际核对。

## 定期运维

- [ ] 检查备份 timer 及执行日志，保留异机副本，并在独立库完成恢复演练。
- [ ] 使用 HTTPS 时验证证书续期；临时 HTTP/IP 尽快切换 HTTPS，修改可能暴露的密码。
- [ ] 查看 5xx、401/429、CF 校验失败、ABC 数据异常、磁盘、内存和队列等待，按需处理。
- [ ] 重新审计依赖与目标 Java/MySQL/Nginx 补丁；历史“无漏洞”结果不能替代本次检查。
- [ ] 在实际目标服务器做接近 40 人使用行为的混合压测，区分页面读取与集中校验排队；当前没有生产容量保证。

## 可规划的工程改进

- [ ] 增加备份失败、外部数据同步失败、健康异常的主动告警；当前主要依靠日志和人工检查。
- [ ] 引入可追踪版本的数据库迁移，逐步替代启动时分散的补结构 SQL。
- [ ] 如需修改密码后强制其他设备退出，补齐普通资料修改密码的会话撤销；目前只有超管密码重置显式注销该用户全部会话。
- [ ] 统一旧单题 regenerate 与双题位管理语义，再移除经确认不再使用的兼容入口；不能只按旧文档删表。
- [ ] 根据实测决定是否需要集中任务队列、跨进程锁与共享缓存；完成前保持单后端实例。
- [ ] 如需再次支持更旧提交或强制“当天提交”，先明确业务规则，再修改每日题校验；当前只查最近 30 条且不另设提交日期门槛。
