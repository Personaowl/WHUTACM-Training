# 界面设计与回退记录

## 2026-10-25：内部页面轻量润色

- 首页训练快捷入口移到页面底部题单卡片下方，与题单同列同宽；平台概览下方不再堆叠入口，小屏按题单、快捷入口、排行顺序排列。
- 桌面今日训练与平台概览在有内容时采用网格自然等高，只对齐外框，不缩放题卡或写死高度；加载、空状态及小屏保留内容自然高度。
- 首页、个人资料卡、题单详情标题与账号绑定卡头部复用静态同心圆线条；保留布局、大字号及平台官方标识，不在表格、热力图、数据指标区叠加装饰。
- 首页横幅收淡背景色块；补题操作按钮统一到 44px，间距调整为 8px，小屏操作区独占一行、复选框为 24px，待补数量与删除操作增加清晰的色彩区分。
- 圆线组件不发请求、不运行计时器或动画，位于内容下层且不接受点击和焦点；系统高对比度模式隐藏装饰。业务接口、编辑权限、统计口径不变。

## 2026-10-25：登录页背景衔接

- 保留墨蓝封面、大字号和登录框。中间不再用透明渐隐，改为清晰的椭圆弧边缘与 4px 浅蓝衬边；桌面沿右缘展开，小屏改为底部 24px 浅弧，不改变表单排布。
- 登录与注册页右下角增加浅蓝、薄荷绿及淡紫的静态 SVG 曲线，位于表单下层，不接受点击、不参与键盘焦点，无额外请求或持续动画。
- 桌面底部增加三道低对比度同心圆弧，跨过深浅背景衔接原有圆形装饰；表单始终处于装饰上层，小屏隐藏跨栏圆弧，保留原有轻量背景。
- 收淡右侧浅色背景；WHUT-ACM 标题与左上标识文字使用浅蓝、淡紫到薄荷绿的静态渐变，保留纯色回退和系统高对比度显示。边界本身不使用模糊、渐隐或额外动画。

## 2026-10-25：统一分隔、字号与首页多平台概览

- 首页不再只显示 CF，复用个人中心面板的紧凑四平台切换；“详细数据”带上所选平台，未绑定和失败均有独立状态，不增加逐题统计来源。
- Rating、历史最高、解题数统一使用共享数字字号（桌面 36px / 小屏 30px）及 800 字重；加强账号区、指标间与详情区的 2px 分隔，保留浅色主题。
- 原来的一次性 1.6 秒扫光改为 14 秒低频循环，每轮约 6 秒缓慢经过、剩余时间静置，淡入淡出避免复位闪光；仅变换与透明度，无循环 JS 定时器。页面隐藏或区域离屏时暂停，系统减少动态效果时关闭。按用户要求不增加暂停按钮。
- CF 图表改为动态导入，首页不加载详情脚本，也不发起详情请求；展开个人中心详情后才加载。

- 第二次收敛改为“账号在左、关键指标在右”的摘要；当前 Rating 为首要数字，历史最高和解题数降低视觉权重。取消三个等大的色块和选中平台的重复图标，洛谷 / Nowcoder 数字账号明确标为 UID；手机上依次排布，不压小字号。

- 按 ui-ux-pro-max 检查键盘焦点、选中状态、未绑定/失败状态及小屏布局。站内热力图与外部平台数据分开，原有公开成员页不扩展私有账号信息。

## 视觉与动效约束

- 使用现有 Lucide 图标，主要功能图标线宽 2.2，主要卡片和控件轮廓 2px，常用图标按钮至少 44×44 CSS px。
- 蓝、紫、绿为浅色分区配色；状态仍配合文字，不单独依赖颜色。
- 只在首页概览及登录封面使用低频扫光，动画限于变换和透明度；当前时序与自动暂停规则见上方记录。不使用常驻粒子、画布循环、外部动效库或新字体请求。
- 系统启用“减少动态效果”时，扫光隐藏并停用动画。表单、键盘焦点和业务操作不依赖动画结束。
