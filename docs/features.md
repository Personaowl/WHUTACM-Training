# 功能与权限说明

[文档索引](README.md) · [项目首页](../README.md)

本文按 2026-10-23 当前实现汇总功能与权限。接口字段见 [接口参考](api-design.md)，存储细节见 [数据库结构](db-design.md)。

## 功能概览

| 模块 | 当前功能 |
| --- | --- |
| 账号与资料 | 注册、登录、修改展示名称和简介；姓名、学院、班级均为选填；自行上传头像，未上传或加载失败时显示默认头像 |
| 账号绑定 | 独立页面，支持 Codeforces、AtCoder、洛谷和牛客账号所有权验证 |
| 每日一题 | Easy / Hard 两个档位、提交校验、积分、标签显示开关、历史记录、加入个人题单 |
| 自主练习 | 难度上下限从 800～3500 按 100 一档选择；最多 5 个标签，按同时包含匹配；保存抽题历史，不校验提交 |
| 题单 | 个人题单、全站唯一公共投稿题单、管理员只读分享题单三种形式；每日题、自主练习和补题计划可加入有写权限的题单 |
| 补题计划 | `/upsolve` 独立页面，仅本人可见；保存链接及选填名称、备注，手动完成/撤销、编辑删除，可加入题单；不自动校验、不计训练积分 |
| Codeforces 数据 | 查看自己及其他成员公开的 Rating、做题数、比赛记录和彩色标签分布图；概览统计最多取最近 10000 条提交，采用缓存快照，不承诺全历史实时数据 |
| 近期比赛 | 聚合 Codeforces、AtCoder、牛客、洛谷比赛信息，展示受公开数据源可用性影响 |
| 首页 | 训练概况、CF 概览、排行榜、训练热力图及每日题训练入口 |
| 排行榜 | 按总积分排序，分页展示，不包含超级管理员 |
| 训练看板 | “每日一题”“每周一赛”“周训练记录”三个子页面，支持完成情况统计、成员资料展示、情况说明审核及当周状态调整 |
| 我的周训练 | 周一至周日汇总自己的每日题与 ABC 记录；切换历史周，提交特殊情况说明，查看管理员意见与处理记录 |
| Excel 导出 | 含今天最近 7 天、最近 30 天或全部记录（非自然周/月）；可组合每日题、CF Rated 比赛与已跟踪 ABC，不含自主练习 |
| 用户管理 | 按账号、展示名称、姓名或学院搜索，管理现役身份；超级管理员可调整角色及重置其他非超级管理员用户密码 |

### 每日题与积分规则

- 默认 Easy 为 **800～1800**，Hard 为 **1900～3000**，范围可在后端配置中调整。
- 每天只展示当前有效的 Easy 和 Hard，管理员重抽后的旧题不会继续作为额外每日题展示。
- 校验要求提交属于已绑定的 CF 账号、题目匹配且判定为 `OK`。
- 校验仅查询账号最近 **30 条提交**，找不到时不回退全量查询。请尽量在提交通过后及时校验。
- 当前没有额外比较提交创建时间与当天零点/题目生成时间；不能据此宣称“只接受当天的新提交”。接口只校验任务创建时的目标日期，不提供选日期补卡。
- 校验采用异步任务，排队后查询结果；重启可能使未完成的内存任务失效，但已保存完成状态和积分不会丢失。
- 每日积分取当天完成题目的最高分，**不将 Easy 和 Hard 相加**。先完成 1200 分 Easy，再完成 1900 分 Hard，当天总分为 1900，第二次新增 700 分。
- CF 题库缓存题目元数据，不保存题面、测试数据或用户代码；目前不包含 Gym 题目。
- Easy/Hard 的更换使用对应题位“重抽”。兼容的“重新生成每日一题”接口仍只更新旧单题快照，不等于同时重抽两档；重抽不撤销已记积分。

### 头像与 ABC

- 头像仅支持自行上传。浏览器裁剪压缩后，图片以 data image 保存在数据库，不依赖 CF 头像服务器；升级时清理旧外部头像地址，保留已上传图片。
- 训练热力图使用平台每日题记录，并非 CF 全部做题数据。
- AtCoder ABC 在开赛后首次处理时冻结现役名单；服务停机期间无法精确还原开赛瞬间名单。参赛记录来自官方公开 History，赛时 AC 来自 AtCoder Problems；无需强制 Rated，默认至少 AC 1 题。
- 默认比赛结束 30 分钟后开始同步；未查到参赛记录时先等待，赛后宽限默认 24 小时后才判缺席，数据异常标记并重试。最低 AC 数（0～8）、宽限（1～168 小时）可配置，也可按场次填写原因豁免；并非固定所有周六一定有比赛。
- 管理员进入“训练看板”默认显示“每日一题”（`/admin/training/daily`）；切换到“每周一赛”（`/admin/training/weekly`）后查看 ABC 历史场次、同步结果、调整规则及管理豁免。页面按需加载，Excel 导出默认勾选当前训练类型，也可组合导出。综合周记录及说明审核见 `/admin/training/records`。

### 洛谷与牛客绑定

绑定页统一显示 Codeforces、AtCoder、洛谷和 Nowcoder；图标使用本地保存的官方站点资产。每张卡片有当前 Rating、历史最高与解题数三个区域：CF 读取已有本地快照，保留 CF 颜色与快照时间；没有快照以及其他未接入平台显示“— / 未同步”，不会将未接入数据显示为 0。绑定验证不受统计区域加载失败影响。

输入个人主页中的数字 UID，开始验证后把完整随机验证码临时加入洛谷“个人介绍”或牛客“个人简介”，保存后返回确认。验证码有效 10 分钟；重新开始至少间隔 10 秒，校验至少间隔 5 秒。成功后可删除验证码。同一平台账号只能绑定一名成员，换绑失败不覆盖已验证的原账号。

服务端只核对对应 UID 的个人简介字段，不以评论、动态或任意页面文本作为证明；不要求密码、Cookie。平台需要登录、验证码、限流或结构变化时会拒绝验证并提示重试，不绕过保护。这次仅保存已验证账号，不改变每日题、ABC 或导出规则，也不自动同步洛谷/牛客训练数据。两个新平台绑定数据仅本人接口可读。

### 周训练记录与特殊情况处理

- 选手入口为“我的周训练”（`/weekly-training`），个人接口始终使用当前登录用户身份，不能查询其他选手的说明；管理员通过训练看板统一查询。
- 以 **Asia/Shanghai 时区的周一 00:00 至下周一 00:00** 为一周，日期选择器会归到对应周一；支持前后周及历史日期查询，不允许查询未来周。
- 每天至少完成一道平台每日题计 1 天，Easy/Hard 和重抽记录不重复计天，周目标为 7 天；周赛沿用 ABC 的正式参赛及最低 AC 规则，周内多场 ABC 任一场达标即可。单场既有豁免仍生效。
- 本周尚未结束且未完成全部要求时显示“进行中”。历史周中，ABC 未同步、数据异常或未发现场次显示“待确认”，不直接认定缺席；确实无赛等情况可由管理员核实后调整周状态。
- 自动统计始终读取本地每日题与 ABC 数据，查看周记录不会即时逐人访问外部网站。既有 ABC 同步任务或管理员“同步结果”更新数据后，可刷新周记录。
- 选手可提交/更新最多 2000 字的特殊情况说明，更新后重新进入待审核。管理员可同意并设置“已达标 / 已豁免 / 未达标”，或恢复自动判定，也可不同意并给出意见。所有处理意见对本人可见。
- 人工状态只作用于该成员的该周，不改题目、比赛原始记录或积分。重新提交说明或不同意说明不会悄悄撤销此前人工状态；需要撤销时管理员显式选择“恢复自动判定”。
- 说明、审核和状态调整均留存操作记录，界面展示最近 20 条。保存使用事务及版本校验，避免两个管理员重复处理，或旧页面覆盖选手新提交的说明。
- 新功能启用后定期保存当周现役名单，已有周记录在退役后仍可查看。启用前的历史只能基于现存记录和当前现役名单汇总，无法还原过去未记录的入队/退役日期。
- 原有 Excel 导出仍导出原始每日题/比赛记录，不包含人工周状态及私人情况说明；迁移时完整备份业务库即可保留周记录与审核历史。

## 个人补题计划

侧栏“补题计划”及首页快捷入口进入 `/upsolve`，无需绑定竞赛账号。快速粘贴 http/https 题目链接即可保存；不填名称时用站点和链接末段命名，可在添加弹窗或编辑中补充名称和备注。不会请求外部平台抓题。

“待完成 / 已完成”分别每页 20 条，默认显示待完成。勾选完成后移到已完成，刷新或重新登录不会丢失，取消勾选可恢复；再次标记已完成不会刷新原完成时间。不同状态中的同题重复添加会提醒，不会产生第二条记录。手动删除才真正移除记录，删除前需确认。

两种状态均可通过现有“加入题单”弹窗收藏，默认带入名称、链接和备注；题单副本与补题记录独立，不会因删除或撤销完成联动删除。该记录不作为每日题校验、周训练、积分或导出的依据，也不提供管理员查询他人清单的接口。

## 共享题单与旧推题下线

共享入口 `/shared-problem-lists` 分为“公共题单”和“专题分享 · 只读”，个人题单仍在 `/problem-lists`。公共题单全站唯一，所有登录成员可直接加题，作者可修改自己的贡献，管理员可维护全部投稿；不能删除公共题单或修改它的名称/可见性。管理员可创建自己的只读专题分享，其他成员及其他管理员都只能查看，不能添加、编辑或删除其中题目。创建者可维护自己的分享；私人题单不变。

旧推题链路已移除。升级新增 community_key 唯一标识，旧共享题单保留所有内容并默认恢复为只读分享，不自动搬入公共题单，也不删除历史贡献。公共题单首次读取列表时自动创建；无需手动配置。上线前完整备份数据库。

## 权限

角色与队员身份独立：`USER` / `ADMIN` / `SUPER_ADMIN` 控制权限，普通成员 / 现役队员用于训练统计。

| 角色 | 权限 |
| --- | --- |
| USER | 个人资料、绑定、每日题、自主练习、个人题单、公开成员数据与共享题单协作 |
| ADMIN | 普通用户功能，以及训练看板、导出、每日题管理、用户列表/现役身份管理、创建普通用户、发布只读题单及公共投稿维护 |
| SUPER_ADMIN | 管理员功能，以及角色调整、密码重置等受限操作 |

超级管理员可将其他非超级管理员用户密码重置为 `123456`，同时撤销其登录会话；用户重新登录后应及时修改密码。不能通过此功能重置自己的密码或其他超级管理员密码。

注册必填站内账号、展示名称和 8～64 位密码；邮箱、姓名、学院、班级可选。普通用户只可修改自己资料，普通管理员不能修改他人账号凭据；超管可通过资料接口修改他人信息。最后一位超管不能被降级。只读分享仅创建者可维护，公共投稿仅作者与管理员可维护。历史只读分享已有他人贡献时仍禁止改为私有，以保留原有贡献的可见性。

独立每日签到、签文和签到日历已移除；本文的每日题“打卡”专指提交校验，不是额外签到活动。
