## 建议阅读顺序

- 了解平台或准备课程材料：项目首页 → 功能与权限 → 开发指南中的分层说明 → 接口/数据库。
- 本地运行：本地开发。
- 新服务器上线：生产部署；先用 IP 时选择临时 HTTP/IP 章节。
- 从旧机搬迁：生产部署准备新机 → 数据迁移 → 发布与日常运维。
- 日常维护：运维 → 维护检查清单。

## 同步约定

新增/修改路由、DTO 或权限时更新接口参考；改建表、索引、存储语义时更新数据库说明；改业务规则时更新功能文档；改部署模板时同步部署与运维步骤。源码仍是精确实现依据。

当前同步范围是**本地仓库代码与模板**，不代表已经读取或修改服务器上的实际 Nginx、环境文件、数据库及自装发布脚本。历史记录中的验证结论也不能当成本次验收结果。
